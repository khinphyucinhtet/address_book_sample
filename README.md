# Address Book Application

## Objective
A simple Address Book application built using plain JavaScript. All contacts are stored in memory using an array. No backend, database, framework, or external library is used.

## Features
- Add a new contact
- View all contacts
- Search contacts by name
- Delete a contact by id

## Contact Data
Each contact has:
- id
- name
- phone
- email

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add, search, view, and delete contacts.

## Note
The data is stored only in memory, so contacts will disappear when the page is refreshed.
